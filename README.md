# Assignment #5 — JavaScript Basics

A multi-page front-end project demonstrating JavaScript fundamentals, DOM manipulation, browser events, a calculator, and an interactive To-Do list.

## Tasks included
- **Task 0:** First Script — `console.log()` and alert message
- **Task 1:** Variables & Operators — string, number, boolean, arithmetic, string concatenation
- **Task 2:** Changing Content — update a paragraph with `textContent`
- **Task 3:** Changing Styles — update background color and font size
- **Task 4:** Creating & Removing Elements — add/remove `<li>` elements
- **Task 5:** Mouse Events — `mouseover` and `mouseout`
- **Task 6:** Keyboard Events — live text using `keyup`
- **Task 7:** Calculator — addition, subtraction, multiplication, and division
- **Task 8:** Interactive To-Do List — add, complete, and delete tasks using an array

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Use the navigation bar to open each task.
4. For Task 0 and Task 1, open Developer Tools → Console to see `console.log()` output.

No build tools or dependencies are required.

## Publish
### GitHub Pages
1. Push all project files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.
5. Wait for the published URL and open it to test all task pages.

Alternatively, deploy the repository using Netlify.
